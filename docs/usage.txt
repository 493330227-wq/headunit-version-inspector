车机版本检测 1.3.0 安装说明

将 APK 复制至 U 盘，在车机文件管理器中打开安装。与旧版同签名，可以直接覆盖升级。
打开即离线读取本机信息。先查看标称版本和真实版本（检测推定），再进入 DiPlay 推荐页。
Android 7.1 / API 25 及以上现在推荐官方 0.2.15 公开预览版；页面提供符合门槛的旧版备选。
新支持的 Android 7.1–8.1 尚未完成车机验证，后装车机不保证兼容。已能使用的 DiPlay 建议保留。
GitHub 按钮打开外部浏览器；无浏览器时可复制链接到手机或电脑下载。选择 Assets 中对应 .apk。
检测推定不是绝对证明，不能保证 CarPlay 硬件兼容。
测试覆盖 Android 9 模拟器，尚未在你的实体车机验证。
演示页面使用模拟数据；APK 使用本机实时数据。
